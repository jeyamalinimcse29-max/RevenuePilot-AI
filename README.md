## 🌟 What is RevenuePilot AI?

**RevenuePilot AI** is a bounded autonomous revenue-growth agent for merchants operating on Razorpay Test Mode.

It analyzes merchant business signals (abandoned checkouts, failed payments, purchase histories, and checkout behavior) to identify recoverable revenue opportunities, reason about the best recovery strategies, and execute bounded actions with human-in-the-loop merchant approval.

---

## 🔄 The 10-Stage Autonomous Agent Loop

```
OBSERVE (Database Signals)
  ↓
ANALYZE (Opportunity Engine)
  ↓
IDENTIFY OPPORTUNITY (Candidate Generation)
  ↓
REASON / PRIORITIZE (AI Agent + 0–100 Scorer)
  ↓
RECOMMEND ACTION (Bounded Strategy Formulation)
  ↓
MERCHANT APPROVAL (Backend Policy Gate)
  ↓
BOUNDED ACTION (Recovery Link / Smart Retry)
  ↓
RAZORPAY TEST MODE (Customer Checkout)
  ↓
OBSERVE & ATTRIBUTE (HMAC Verification)
  ↓
AUDIT (Immutable Ledger & Metrics)
```

## 🛡️ Architecture: Deterministic Logic vs. AI Reasoning

| Layer | Responsibility | Technology |
| :--- | :--- | :--- |
| **Deterministic Backend** | Payment verification, 0–100 transparent scoring, HMAC-SHA256 signature checks, approval policy gates, revenue attribution, idempotent webhooks. | SQLite (`better-sqlite3`), Node crypto, Next.js App Router |
| **AI Agent Layer** | Contextual reasoning, signal interpretation, strategy prioritization, structured recommendation generation, grounded copilot conversation. | Google Gemini / Intelligent Grounded Reasoning Engine |
| **Merchant Control** | Reviewing evidence, approving/rejecting bounded actions, inspecting audit trails. | Tailwind CSS, Lucide React, Next.js |

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment (Optional)
Copy `.env.example` to `.env.local` if you wish to configure live Razorpay test keys or Gemini API keys:
```env
RAZORPAY_KEY_ID=rzp_test_demo123456789
RAZORPAY_KEY_SECRET=demo_razorpay_secret_key
GEMINI_API_KEY=
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
*(Note: RevenuePilot AI includes a built-in Razorpay Test Simulator and deterministic reasoning fallback, allowing 100% full-featured evaluation out of the box without external API keys!)*

### 3. Run Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### 4. Run Automated End-to-End Verification Test Suite
```bash
npx tsx test-e2e.ts
```

## 🧭 Key Views & Routes

- **Merchant Dashboard (`/`):** Real-time revenue metrics, top revenue opportunities, and recent recovery stream.
- **AI Agent Hub (`/agent`):** Deep dive into detected signals, transparent scoring factors (+30 Cart, +25 History, +20 Recency, +20 Intent), AI rationale, and 1-click Approve/Reject.
- **Opportunities Manager (`/opportunities`):** Filter and search candidate opportunities across abandoned carts and failed payments.
- **Payment Intelligence (`/payments`):** Real-time transaction ledger with decline diagnostics and recovery attribution tags.
- **Customer Intelligence (`/customers`):** RFM customer segmentation (Loyal, High Value, At Risk, Inactive, New).
- **Audit Trail (`/audit`):** Immutable chronological log of all AI observations, approvals, tool calls, and Razorpay payments.
- **Evaluation Demo Center (`/demo-center`):** 1-click simulation triggers for judges to test scenarios without manual checkout friction.
- **Customer Storefront (`/store`):** Public customer store to simulate real shopping, cart abandonment, and Razorpay test checkout.
- **Customer Recovery Portal (`/recover/[token]`):** Dynamic restored cart checkout link generated by the agent upon merchant approval.
- **Merchant AI Copilot:** Interactive conversational assistant grounded in real database tools with zero hallucinations.

## 🏆 Hackathon Judges Checklist

1. **"What revenue problem did the agent find?"** $\to$ High-intent abandoned checkouts (e.g. ₹4,999) and payment card declines (e.g. ₹7,499).
2. **"Why did it choose this opportunity?"** $\to$ Transparent 0–100 score breakdown (+30 Cart Value, +25 VIP History, +20 Urgency, +20 Intent Stage).
3. **"What action did it recommend & why?"** $\to$ 1-Click Cart Recovery Link with courtesy loyalty discount or Smart Retry Link.
4. **"Did the merchant approve it?"** $\to$ Backend Policy Gate strictly enforces human-in-the-loop merchant approval before link activation.
5. **"Did the Razorpay transaction happen?"** $\to$ Customer completes checkout via Razorpay Test Mode with HMAC-SHA256 signature verification.
6. **"How much revenue was recovered?"** $\to$ Deterministic revenue attribution links Opportunity $\to$ Action $\to$ Payment, instantly incrementing recovered revenue in the ledger.
7. **"Can I audit the entire chain?"** $\to$ Full immutable audit trail persisted with full JSON metadata.
